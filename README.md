# Linux System Monitor

A command-line system monitoring tool built with Python for Linux.

## Project status

Currently under development.

## Initial goals

- Display general system information.
- Monitor CPU usage.
- Monitor memory usage.
- Monitor disk usage.
- Display system uptime.
- Inspect running processes.
- Export monitoring results.

## Learning goals

- Work with Linux system information.
- Read and parse files from the `/proc` filesystem.
- Practice Python functions and data structures.
- Build a command-line interface.
- Apply testing and logging.
- Use Git troughout the development process.

## Development environment

- Ubuntu Linux
- Python 3
- Visual Studio Code
- VSCode Remote SSH
- Git and GitHub
